# Change Chief settings

## Open Settings and save changes

From **Overview**, click the **Settings** gear, press **⌘,**, or choose **Settings…** from the Chief menu. If you're reading a conversation or a Super Thread, press **⌘K** to return to Overview first.

Under **General → Interface preferences**, choose **System**, **Light**, or **Dark** in **Appearance**. Under **Interface language**, choose **English** or **Simplified Chinese**. These choices save immediately, even when your agents are unavailable.

Agent changes save when you close Settings. If the panel stays open, check the message and complete any required choices. If a save error appears after the panel closes, reopen Settings and click **Retry saving**. If the saved settings changed elsewhere, choose **Keep my changes and retry** to apply your choices or **Discard draft and load latest settings** to use the saved ones.

## Choose who coordinates and who can take tasks

On the **Chief** tab, use the map to choose the coordinating agent at the top and at least one agent it can assign tasks to below. Complete any required model choices. Before switching the coordinating agent, finish work that's running, waiting for a response, or waiting to send. Switching to a different agent starts a new Chief conversation and keeps your note.

Use **Model selection preferences** to guide Chief's choices for future tasks. Pick **Economy**, **Balanced**, or **Performance**, or select **Custom** and describe what you prefer. Hover over any option’s info icon to read its description. Chief keeps your custom text if you switch presets. Chief chooses from the agents you've enabled and the models available when it assigns the work.

## Set up Tag Agent and Super Thread Agent

Use **Tag** to set up Tag Agent and **Super Thread** to set up Super Thread Agent. You can turn either one on independently. Hover over an option’s info icon to see what it does.

- **Agent off** stops automatic work for that role and keeps its existing tags or Super Threads and saved choices.
- **Use Chief** uses Chief's agent and model settings for future work.
- **Configure separately** lets you choose an agent and model for the role. Chief keeps those choices if you later switch to **Use Chief** or **Agent off**.
