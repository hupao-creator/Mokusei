# Mokusei 产品指南

Mokusei 把交给不同 Agent 的工作放在同一个 Mac 工作区里。你可以请 Moku 安排任务，再回到各个会话看结果、回答问题或继续交代工作。

## 怎么安装并开始使用？

- 从邀请方取得 Mokusei Alpha，安装应用、准备 Agent 并发出第一条请求。[首次使用](getting-started.md)

## 我该在哪里交代任务？

- 了解输入发给谁，怎么指定项目目录，以及到哪里读 Moku 的答复和笔记。[与 Moku 协作](working-with-moku.md)
- 直接补充任务、添加附件，或从较早一次执行另起一条会话。[Agent 会话](task-conversations.md)

## 怎么看进展、处理确认或停止任务？

- 在俯瞰查看哪些任务在运行，哪些正在等你，并了解何时可以归档。[会话俯瞰](overview.md)
- 查看当前与以往的执行、回应提问并停止任务。[Agent 会话](task-conversations.md)
- 一边读会话，一边看本次执行或给网页写批注。[侧卡](sidecards.md)

## 怎么找回工作结果或调整以后如何分工？

- 用目录和标签缩小范围，并从报告查看关联工作和卡片上的改动概况。[标签、报告与文件改动](reports-tags-and-changes.md)
- 调整 Moku 的分派范围、标签和报告助手，以及界面语言和外观。[设置](settings.md)
