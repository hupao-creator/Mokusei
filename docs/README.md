# Chief Product Guide

Chief brings Codex, Claude, Pi Agent, and OpenCode into one Mac workspace. Ask Chief to coordinate your work, then open a task conversation when you want to check progress, answer a question, or give the agent more direction.

## Set up your workspace

- Install Chief Alpha, connect an agent, and send your first request. [Getting started](getting-started.md)
- Choose which agents can take tasks, set up automatic tags and reports, or change the app's language and appearance. [Settings](settings.md)

## Give instructions and follow the work

- Send a request to Chief, point it to a project folder, or find its replies and notes. [Working with Chief](working-with-moku.md)
- Find a task, see what needs your attention, and hide work you no longer need on the canvas. [Overview](overview.md)
- Read a result, answer a permission request, send a follow-up, or branch from an earlier run. [Agent conversations](task-conversations.md)
- Watch a live run beside earlier messages, or mark up a web page and send feedback. [Sidecards](sidecards.md)

## Find related work

- Use tags to find work in a folder, browse reports and their sources, or check which files changed. [Tags, reports, and file changes](reports-tags-and-changes.md)
