# 阅读页的 Overview 隔离与静态开销

2026-11-04，基于本地 main `9b6b515`，按用户最终要求提交并合入本地 main，不推送；后续实测由用户接手。

## 问题与验收目标

用户在“调研 Pi Durable 理念及借鉴”上做了控制变量：从全部卡片打开后滚动卡顿；
搜索 durable 仅剩一张卡片时滚动流畅。要求展开后尽量停止背景 Overview 的显示工作，
同时查清没有 active card 时的静态开销。本次不改变任务执行、内容订阅或数据接收。

1. 阅读期间，背景只保留外观和返回所需状态。
2. 返回前恢复最新内容与窗口尺寸；筛选、相机位置和原生控件身份保留。
3. 静止时不持续计算与请求重绘；眨眼、运行、表情交接仍正常。
4. 快速关闭、切换、删除卡片及窗口变化不让旧异步工作恢复过期界面。

## 实测与原因

卡片没有 active execution 并不意味着整个窗口没有 display-link 工作。采样抓到
Moku 的 `displayFrame → sample → target → NativeMokuRunningGeometry`：只要任一
原生绘制座仍可见，就一直算姿态并标记重绘。Agent 输入已翻成 Harness logo，眼睛
被移除，但空的装饰绘制座仍挂载，因此同样维持空转。这不来自已完成卡片的云或计时器。

原先 Overview 仅降低 opacity、加 blur、禁用输入并暂停显示投影，原生树仍留在窗口的
活动布局/绘制层级中。原生滚动采样中还存在 AppKit tracking/cursor 区域更新。
开发版布局诊断确实会扫描原生树，但短时采样没有把它确认为主热点；本次没有关闭诊断
或把收益归给日志开关。

最初“全部 vs 搜索”的静置比较还混入搜索隐藏 Moku 的变化，不能当作卡片数量的
单一因果证据。后续增加同样显示 Moku 的单 Tag 对照：原版全部卡片约 5.4%，单卡片
约 5.1%。两者都有明显的固定空转成本。

## 实现决定

外层阅读栈采用独立的原生 Overview host。面板运动和标题交接完成后，截取一次背景
外观并隐藏真实 host；窗口变化仅缩放这张背景图。关闭准备时解除隐藏、同步最新
环境和视口，等待已有 canvas preparation receipt，再采样返回位置。取消截取按代次
隔离，返回和销毁释放图片。SwiftUI owner、卡片、筛选和相机状态没有卸载；嵌套历史
阅读栈保留原来的宿主策略。

Moku 缓存非 running 的精确目标姿态，输入变化时失效。保留绝对时间的 4.2 秒眨眼
周期与 0.32 秒闭合过程；其间暂停 display link，只安排下一次眨眼唤醒。没有眼睛且
没有运动内容时连眨眼唤醒也不安排。运行、表情交接和退休装饰继续推进到最后一帧，
唤醒重置 wall-time 基准，避免睡眠时间挤入下一段运动。

## 验证方式与边界

目标机为 Apple M1 Pro、macOS 26.5.1，Debug 开发包，真实 profile 中全部 31 张卡片。
按用户后续要求，页面操作改用内置 Unix-socket interaction API，未发送任务或编辑正文。
原始记录位于 `/tmp/mokusei-overview-reading-20261104/`。

静置测量每次约 10 秒，期间无截图、采样器和持续 API 轮询。程序滚动调用真实
`reading.control / scrollTo`：同一 4841pt 文档、715pt 视口，从 0 开始，0–1200pt
往返四轮，共 240 次接受的操作，最终确认返回 0。过期 handle 被明确拒绝后才重新
观察；不重发结果未知的操作。首次两个驱动版本未等新 handle，失败记录仍保留。

API 每次动作更新控件注册代次并返回整个窗口快照，程序滚动还会引发 SwiftUI
ScrollPosition 更新。其 CPU 时间和命令延迟包含这些额外工作；请求 30Hz 并不代表
实际达到 30Hz，更不能换算为触控板滚动或屏幕 FPS。此次没有光学帧率验收。

## 回归中发现并处理的问题

首次隔离版本在面板运动完成后立即截取背景，生产标题回放出现真实文字未接手。
同一生产模块关闭隔离的对照通过；将截取推迟到 live heading 完成交接后，保留全部
中间帧与原有断言的隔离回放通过。

新增的原生 host 检查首次编译缺少 MainActor 标注，已修正。原有 landing 用例仍要求
Agent detail 保留旧眼睛，与已落地的 Harness 翻牌设计冲突；改为检查进入时眼睛退出、
返回时重新出现，普通 Moku 角色变化的身份连续性断言保持。

眨眼回放的原判据仍裁剪旧浅色胶囊并寻找黑色眼睛。失败截图实际是深色胶囊的白眼睛，
因此没有获得任何右眼斜率样本。现按真实原生眼睛座裁剪白色墨迹，移动帧排除大片白色
页面背景；原有闭合比例、恢复比例、样本数量与倾斜上限保留，并用停止眨眼的负对照验证。
