## 条件与口径

固定 10 张已经存在的 Codex 卡片，分别测运行中静置和正文更新。使用同一个正常签名 Release 实验包，以临时环境开关选择原有实时算法、半分辨率、缓存光斑或复用参数。源码基于上述回滚提交；对照是实验包内的原有算法，并非逐字节相同的回滚制品。原型源码、补丁和制品身份全部保留。

MacBookPro18,3、10 核、16 GiB、macOS 26.5.1；内建屏模式及最大刷新率均为 120 Hz，scale 2。所有组固定 1280×950 pt 窗口，6 秒预热、8 秒正式区间、2 秒尾部探针。正式 CPU 轮关闭产品诊断记录，仍使用相同的外部 observed 采集器；没有同时构建或运行采样分析器。CPU 100% 表示一个核，内存是采样物理占用峰值，不是分配器最大值。

每组另有一次静置 GPU 诊断。GPU 数值来自已完成 `MTLCommandBuffer` 的 `gpuEndTime - gpuStartTime`，不是整机 GPU 利用率、GPU 忙碌时间总和或能耗。Apple 要求在完成后读取这些时间；不可用的零值不计为成功的零耗时。[API 文档](https://developer.apple.com/documentation/metal/mtlcommandbuffer/gpustarttime)。详细诊断日志的 CPU 不参与正式 CPU 比较。参数生成耗时是墙钟区间，不是线程 CPU 时间。

各单元只测一次，按对照→半分辨率→缓存光斑→复用参数串行执行，没有随机交叉或置信区间。卡片运动种子和宿主噪声没有成对锁定，不能据小百分比差异下统计回归结论。正文与静置属于不同负载，分别对同场景对照计算变化，不把二者相减解释成正文成本。

## 三个原型的取舍

1. **缓存柔光形状，运动实时计算。** 共享一张 128×128 的径向光斑纹理，每帧沿原轨迹改变每个光斑的位置、半径和颜色。实例化绘制先相加到每卡一张中间纹理，再限幅输出。普通配色仍有 18 个光斑，没有播放整段动画。本版使用 Metal，并没有尝试 Core Animation 属性动画。GPU 耗时下降明显，但多一次绘制 pass 和中间纹理；CPU 正文轮与内存均增加。颜色叠加使用半精度中间纹理，有限尺寸光斑经过插值，尚未做最终视觉验收。
2. **宽高各减半，运动频率不变。** 仅云纹 drawable 从 720×440 变为 360×220，文字和边框仍保持原分辨率。GPU 与内存收益明显，正文 App CPU 没有改善。空间细节变软是需要接受的取舍，放大时的观感尚未验收。
3. **提前计算、缓存和复用。** 运动路径的固定参数及当前段端点缓存到渲染队列，复用几何数组，将半径倒数及颜色/强度系数提前计算，并跳过不再需要的颜色上传。保留实时轨迹和原输出分辨率。参数生成本来只有微秒量级，本轮缩短了这部分工作，但 GPU 收益远小于前两项。它没有减少逐卡 drawable、定时器或命令提交次数。

## 证据边界与交付

所有组保留同一高帧率驱动，没有通过降到 30 fps 或停止动画换取资源下降。GPU 诊断均记录 10 个云纹图层；呈现回调不是屏幕光学 FPS，也不证明正文更新时的实际帧率。没有做像素样式对比。

正文的源预算固定为 160 个 reasoning 片段 / 10240 字节、30 条进度与终结消息 / 2990 字节，四组均观测到 20/20 个 CHECK。八个正式 CPU 场景及四个 GPU 诊断场景的业务/进展结果均为 `passed`，所属进程清理无错误。标题、任务状态和 usage 没有作为高频变化输入；卡片在计时前已经存在。业务进展、源交付和尾部交互由原有外部判据评估，GPU 内部诊断不替代这些判据。

完整 benchmark 的测量状态仍为 `incomplete`，比较状态仍为 `not-comparable`：后代生命周期/退出 CPU 与 native hitch 能力不完整。详细日志没有最终 `sessionEnd`，无法取得最终丢弃记录计数；汇总保留已记录工作之间的对应检查，不据此宣称日志绝无丢失。所有数值仅用于探索性候选筛选。

两个准备失败保留在原始证据中：先是实际窗口高度为 950 pt，不满足原有 820 pt 请求；之后单独的窗口放置仍未达到前台/边界要求。最终使用原有准备步骤完成激活，再通过 AX 将相同 PID/启动身份的窗口放到内建屏，要求实际边界精确匹配 1280×950 且处于前台后才开始。没有修改产品布局算法或正式评分条件。各组统一使用此准备方式，不与历史 1280×820 的数据混合。

未测组合方案、N5/N20、拖动、首次渲染、浅色/混合配色或外接屏。没有运行候选回归测试、`make check` 或远端 CI；这些没有被记为通过。报告 diff、本地链接及 97 份来源文件哈希已复核。当前 CI 分类器未将此 baselines 路径纳入文档快速路径，本次依用户要求不触发远端。本提交仅保存测量报告，生产源码保持回滚后的实现。原型、签名包、每次尝试和完整原始数据保存在本地 main 的 `.scratch/live-cloud-candidates-20261113`，仅合并本地 main。
