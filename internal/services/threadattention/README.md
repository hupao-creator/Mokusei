# Thread attention facts

This package owns the persisted facts for one ordinary thread. A stable visit identity counts one detail entry, and cumulative foreground time makes repeated receipts safe. The completion read marker belongs only to the latest execution. The hide revision protects a model decision from later visits; the generation invalidates queued work across a search recovery or successor execution.

Runtime applies these transitions in its SQLite writer and owns scheduler and search integration. See the [Attention Agent](../../plugins/applications/attention/README.md).
