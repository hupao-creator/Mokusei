# 标签选中样式预览

这是静态浏览器视觉提案，保留原始配色与当时的审查记录，不是当前生产组件或验收截图。
当前标签及搜索转场请使用 [原生标签回放](../tag-filter-morph/README.md) 与
[搜索回放](../overview-thread-search/README.md)；以下尺寸与对比度数据仅描述本 HTML。

直接打开 `index.html`。点击标签或使用 Tab、Enter/空格切换，右上角切换浅深主题。

此页面放大展示原生标签的静态视觉方向（原生高 32 pt，桌面预览高 56 px）。
选中填充和文字使用 `NativePalette.overview` 的 `accentSoft` / `accent`，
描边透明度为 48%，选中计数底色为当前文字色的 6%。
浏览器玻璃效果是近似展示；原生 Liquid Glass、字体与布局以应用为准。

浏览器的 `prefers-contrast: more` 使用深色/白色选中文字及 82% 描边，
`prefers-reduced-transparency: reduce` 为未选中标签使用不透明底色。
选中标签始终使用实色填充。

按 sRGB 配色核算，正常对比度下浅色/深色选中文字约为 4.96:1 / 6.11:1，
计数文字约为 4.59:1 / 5.41:1。它们是实色区域的配色对比度，
不代表未选中玻璃在任意背景下的对比度。

审查时已对照独立原生窗口的浅深主题截图，并检查页面的鼠标/键盘选择、
窄窗口滚动、焦点环和增强对比度。
原生“减少透明度”和“增强对比度”分支通过代码审查确认；
未修改用户系统设置来测试这两项。
